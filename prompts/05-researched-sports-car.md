# Real-world object, researched first

Source: [3d-agent.com/docs/example-prompts](https://3d-agent.com/docs/example-prompts) (copied 2026-09-25).

> Look up the real proportions of a classic 1960s sports car, then write a plan to model it. Don't build yet.

Review the plan, ask for changes, then say *Build it phase by phase*. Real proportions and an approved plan beat guessing.
