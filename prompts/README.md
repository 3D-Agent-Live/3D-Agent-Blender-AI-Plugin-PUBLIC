# Example prompts for 3D-Agent

These prompts are copied from [3d-agent.com/docs/example-prompts](https://3d-agent.com/docs/example-prompts) (copied 2026-09-25). They come from 3D-Agent users, and most results took two to four prompts. Copy one as a starting point and change the details. Type them in the 3D-Agent app, or send them as the `task` of the `3d_agent` tool from a connected app (see the [main README](../README.md)).
