# Stylized character, in three prompts

Source: [3d-agent.com/docs/example-prompts](https://3d-agent.com/docs/example-prompts) (copied 2026-09-25).

1. *Create a cute, colorful mushroom character in a simple stylized style, on a clean background.*
2. *Keep the same proportions, but turn it into a forest spirit: a translucent cap with glowing veins, standing in a night forest with floating spores, mist and moon rays. Cinematic stylized render with soft volumetric lighting.*
3. *Keep the character and the mood exactly as they are. Only improve the environment: add crystals, natural trees and more foliage for depth.*

Each prompt changes one layer and says what to keep.
